Sentiment Analysis Project

## Objective
To analyze text data and classify sentiments into Positive, Negative, and Neutral categories using Natural Language Processing techniques.

## Dataset
Sentiment dataset.csv

The dataset contains social media text data with sentiment labels and additional information such as platform, country, and engagement metrics.

## Tools Used
- Python
- Pandas
- NLTK
- TextBlob
- Matplotlib
- WordCloud

## Steps Performed
1. Loaded the sentiment dataset.
2. Cleaned text data.
3. Applied tokenization.
4. Removed stopwords.
5. Performed sentiment analysis using TextBlob.
6. Visualized sentiment distribution.
7. Generated a word cloud of frequent words.

## Results
Predicted sentiment distribution:
- Positive: 280
- Neutral: 333
- Negative: 119

## Conclusion
The NLP model successfully analyzed text data and identified sentiment patterns from the dataset.
