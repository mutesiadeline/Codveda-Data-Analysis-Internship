Task 1: Regression Analysis
Overview

This project was completed as part of the Codveda Technologies Data Analysis Internship. The objective was to build a linear regression model to analyze the relationship between variables and predict one variable based on another.

Tools Used
Python
Pandas
Scikit-learn
Methodology
Loaded and prepared the dataset using Pandas.
Selected the relevant variables for regression analysis.
Split the data into training and testing sets.
Trained a Linear Regression model using Scikit-learn.
Evaluated the model using R-squared and Mean Squared Error (MSE).
Interpreted the model coefficients to understand the relationship between the variables.
Conclusion

The project provided practical experience in regression modeling, model evaluation, and interpreting relationships within data.
