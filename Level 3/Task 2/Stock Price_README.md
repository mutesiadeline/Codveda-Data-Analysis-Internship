Task 2: Building a Stock Price Dashboard with Power BI
Overview

This project was completed as part of the Codveda Technologies Data Analysis Internship. The objective was to create an interactive Power BI dashboard for analyzing stock price data and identifying trends over time.

Dataset

Dataset: Stock Prices Data Set.csv

The dataset contains:

Date
Symbol
Open
High
Low
Close
Volume
Tools Used
Power BI Desktop
Power Query
CSV
Key Work
Imported and prepared the stock price dataset.
Created visualizations for stock prices and trading volume.
Added summary cards for key values.
Added date and stock symbol filters/slicers.
Analyzed changes in opening, closing, high, and low prices.
Conclusion

The project provided practical experience in data preparation, visualization, and interactive dashboard development using Power BI. It demonstrated how raw stock market data can be presented clearly to support data analysis and decision-making.
