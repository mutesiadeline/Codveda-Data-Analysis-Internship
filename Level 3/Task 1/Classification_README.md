Task 1: Predictive Modeling – Customer Churn Classification
Overview

This project was completed as part of the Codveda Technologies Data Analysis Internship. The objective was to use machine learning classification techniques to predict customer churn based on customer account and service information.

Dataset

Dataset: churn-bigml-80.csv

The dataset contains customer information such as account length, service plans, call usage, charges, and customer service calls. The Churn variable was used as the target.

Tools Used
Python
Pandas
Scikit-learn
Matplotlib
Seaborn
Methodology

The project involved:

Exploring and preparing the dataset.
Checking for missing values and duplicates.
Handling categorical variables.
Splitting the data into training and testing sets.
Training classification models.
Evaluating model performance using accuracy, precision, recall, and F1-score.

The classification models included Logistic Regression, Decision Tree, and Random Forest.

Results

The models were evaluated on the test data and compared using standard classification metrics. The analysis demonstrated how machine learning can be used to identify patterns associated with customer churn.

Conclusion

This project provided practical experience in data preprocessing, classification modeling, and model evaluation. It demonstrated how predictive analytics can support customer retention and data-driven decision-making.
