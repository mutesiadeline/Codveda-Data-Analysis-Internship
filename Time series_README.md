Task 2: Time Series Analysis
Overview

This project was completed as part of the Codveda Technologies Data Analysis Internship. The objective was to analyze time-series data to identify trends and patterns over time.

Tools Used
Python
Pandas
Matplotlib
Statsmodels
Methodology
Loaded and prepared the time-series dataset.
Converted the date field into a suitable time format.
Visualized the data over time.
Analyzed trends and patterns in the series.
Applied moving average smoothing to identify the underlying trend.
Used time-series decomposition to examine trend, seasonal, and residual components.
Conclusion

The project provided practical experience in time-series analysis and visualization. It demonstrated how historical data can be analyzed to identify trends and patterns over time.
